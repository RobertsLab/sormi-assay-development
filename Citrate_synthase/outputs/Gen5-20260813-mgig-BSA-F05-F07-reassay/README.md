## Files

- [`sample_protein_concentrations.csv`](sample_protein_concentrations.csv):
  Final results, one row per sample -- only samples passing *all* QC (CV
  &le; 15% and within the standard curve's range) are included. All 9
  re-assayed samples (5 from `F05`, 4 from `F07`) passed on this run.

    | Column | Description |
    |--------|-------------|
    | `Sample` | Base sample name, dilution suffix stripped (e.g. `F05_03_ambient`) |
    | `Well ID` | Source plate well ID (e.g. `SPL1`) |
    | `Dilution factor` | Multiplier applied to recover the pre-dilution concentration (`1` for `-df.0`, `N` for `-df.N`) |
    | `Mean 595` | Mean 595 nm absorbance across triplicate wells |
    | `CV 595 (%)` | Technical-replicate CV of raw absorbance |
    | `CV concentration (%)` | Technical-replicate CV of back-calculated concentration (the QC metric used for exclusion) |
    | `Well concentration (ug/mL)` | As-measured concentration back-calculated from the fitted standard curve, *before* dilution correction |
    | `Calculated concentration (ug/mL)` | Final, dilution-corrected sample concentration (`Well concentration` &times; `Dilution factor`) |
    | `In standard curve range` | Whether the sample's absorbance fell within the retained standards' range (`yes`) or required extrapolation |
