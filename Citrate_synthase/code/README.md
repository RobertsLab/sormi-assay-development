`sormi-assay-development/edit/main/Citrate_synthase/code`

Code directory for SORMI protein-quantification (BSA standard curve,
BCA/Bradford-style, 595&nbsp;nm) analyses supporting the citrate synthase
assay development, reading raw data from `../data/BSA/raw_absorbance` and
writing results to `../outputs`.

All file names should adhere to this format:

- `Gen5-YYYYMMDD-<species_abbreviation>-<experiment_description>.Rmd`

    - For `<species_abbreviation>`, use first letter of genus and first three letters of species. E.g. `mgig` for *M. gigas*.

This naming convention keeps with the format used for plate reader
experiment files in `../data/BSA/plate_reader_files` and allows for easy
identification of which code corresponds to which experiment.

All outputs from a script should be directed to a corresponding directory
with the same name (excluding the suffix) in `../outputs`.

---

## Files

- [`Gen5-20260813-mgig-sormi-BSA-F05-protein.Rmd`](Gen5-20260813-mgig-sormi-BSA-F05-protein.Rmd):
  Protein quantification for plate `F05` (16 samples, `F05_01`-`F05_08`
  ambient/36&deg;C, + 8-point BSA standard curve). Computes per-sample
  mean/SD/CV of both raw absorbance and concentration, excludes
  triplicates with CV(concentration) > 15% (including standard-curve
  points), fits the standard curve, and back-calculates sample
  concentrations.

- [`Gen5-20260813-mgig-sormi-BSA-F05-protein.md`](Gen5-20260813-mgig-sormi-BSA-F05-protein.md):
  Knitted (`github_document`) output of the above, with supporting figure
  images in `Gen5-20260813-mgig-sormi-BSA-F05-protein_files/`.

- [`Gen5-20260813-mgig-sormi-BSA-F07-protein.Rmd`](Gen5-20260813-mgig-sormi-BSA-F07-protein.Rmd):
  Same analysis as the `F05` script, applied to plate `F07`
  (`F07_01`-`F07_08`).

- [`Gen5-20260813-mgig-sormi-BSA-F07-protein.md`](Gen5-20260813-mgig-sormi-BSA-F07-protein.md):
  Knitted output of the above, with supporting figures in
  `Gen5-20260813-mgig-sormi-BSA-F07-protein_files/`.

- [`Gen5-20260813-mgig-sormi-BSA-F05-F07-reassay-protein.Rmd`](Gen5-20260813-mgig-sormi-BSA-F05-F07-reassay-protein.Rmd):
  Same analysis, applied to a single re-assay plate carrying the 9 samples
  flagged for re-assay by the `F05`/`F07` scripts. Sample names carry a
  `-df.<N>` dilution-factor suffix (`df.0` = undiluted, `df.N` = diluted
  N-fold); this script additionally back-calculates each sample's
  well-level concentration and multiplies by its dilution factor to
  recover the true, pre-dilution concentration.

- [`Gen5-20260813-mgig-sormi-BSA-F05-F07-reassay-protein.md`](Gen5-20260813-mgig-sormi-BSA-F05-F07-reassay-protein.md):
  Knitted output of the above, with supporting figures in
  `Gen5-20260813-mgig-sormi-BSA-F05-F07-reassay-protein_files/`.

- `Gen5-*-protein_files/figure-gfm/`: Auto-generated by `knitr` when
  rendering each `.Rmd` to `.md` -- contains the standard-curve plot images
  embedded in the corresponding `.md` file. Not edited directly; regenerated
  on re-knit.
