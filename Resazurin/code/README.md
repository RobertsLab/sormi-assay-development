`Resazurin/code`

## DESCRIPTION

R Markdown (`.Rmd`) analysis scripts for the resazurin assay experiments, plus their knitted `.md`/`.html` outputs and figure directories (`<name>_files/`) generated by knitting.

Each `.Rmd` reads from a subdirectory in `Resazurin/data/` and writes to an identically-named subdirectory in `Resazurin/outputs/` — see that directory's README for details. Expected inputs/outputs are documented at the top of each `.Rmd`.

Filename prefixes indicate analysis stage:

| Prefix | Purpose |
|--------|---------|
| `01.00-resazurin-<experiment>` | Per-experiment raw fluorescence, blank correction, metabolism, and AUC analysis |
| `02.00-resazurin-raw-all-*` | Raw fluorescence comparison across multiple experiments sharing a condition (e.g., all 36°C heat-stress experiments) |
| `03[.5]-resazurin-*` | Curve-feature extraction across experiments |
| `04[.1]-resazurin-family-phenotype-prediction[-slides]` | Family-level phenotype prediction modeling and presentation slides (`.qmd`) |

---

## FILES

- `<name>.Rmd` — Source R Markdown analysis script.
- `<name>.md`, `<name>.html` — Knitted GitHub-flavored and HTML renders of the corresponding `.Rmd`.
- `<name>_files/` — Figures embedded in the knitted `.md`/`.html` renders.
