# 1 Background

**Question:** *Does the shape of a resazurin curve identify which stress
an oyster experienced, and which curve features carry that signal?*

This notebook applies the notebook-04 framework (feature screen →
cross-validated prediction → composite index) to the 20260921
multi-stress run. 04 predicted a family’s *survival* from family-mean
curve features. Here there is a single family and **six distinct
stresses** (plates `C`, `R`, `S`, `T`, `U`, `V`), none of which is a
control. The unit of prediction is therefore the **individual oyster**,
and the target is **which of the six stresses** it was exposed to.

| 04 (family phenotype)                     | 05.1 (multi-stress)                                  |
|:------------------------------------------|:-----------------------------------------------------|
| Family-mean features (n ≈ 9 families)     | Per-individual features (n = 72; 12 per stress)      |
| Spearman correlation with survival        | Kruskal-Wallis effect size (ε²) across six stresses  |
| Stress contexts (`sw_heat`, `fw_heat`, …) | Curve windows (acute 0–2 h, full 0–18.75 h)          |
| Leave-one-family-out CV regression        | Leave-one-oyster-out CV classification (LDA)         |
| Composite resazurin index                 | Stress-signature PCA and composite suppression index |

Each stress is also characterised **on its own**: for every stress,
which features set it apart from the other five (one-vs-rest).

## 1.1 Caveats (read first)

-   **One plate per stress**: plate and stress are confounded, so a
    “stress signature” could partly be a plate effect.
-   **Few timepoints** (7, with a single 2 → 18.75 h interval): slope
    and timing features are coarse, and full-run features are dominated
    by the overnight read.
-   **Stress names** are not yet in `layout.csv`; results use plate
    letters.

# 3 Helper Functions

Curve-feature extraction is taken from notebook 03.5 so feature
definitions match across the repo.

``` r
safe_divide <- function(num, den) {
  if_else(is.finite(num) & is.finite(den) & abs(den) > .Machine$double.eps,
          num / den, NA_real_)
}

trapezoid_auc <- function(time_hr, value) {
  ok <- is.finite(time_hr) & is.finite(value)
  t <- time_hr[ok]; v <- value[ok]
  if (length(t) < 2) return(NA_real_)
  ord <- order(t); t <- t[ord]; v <- v[ord]
  sum(diff(t) * (head(v, -1) + tail(v, -1)) / 2)
}

segment_auc <- function(time_hr, value) {
  ok <- is.finite(time_hr) & is.finite(value)
  t <- time_hr[ok]; v <- value[ok]
  if (length(t) < 2) {
    return(tibble(t_start = numeric(), t_end = numeric(),
                  t_mid = numeric(), auc = numeric()))
  }
  ord <- order(t); t <- t[ord]; v <- v[ord]
  tibble(t_start = head(t, -1), t_end = tail(t, -1),
         t_mid = (head(t, -1) + tail(t, -1)) / 2,
         auc = diff(t) * (head(v, -1) + tail(v, -1)) / 2)
}

classify_trajectory <- function(slopes, slope_tol = 1e-12) {
  if (length(slopes) == 0 || all(!is.finite(slopes))) return(NA_character_)
  s <- slopes[is.finite(slopes)]
  signs <- case_when(s > slope_tol ~ 1L, s < -slope_tol ~ -1L, TRUE ~ 0L)
  nonzero <- signs[signs != 0L]
  if (length(nonzero) == 0) return("stable")
  if (all(nonzero > 0)) return("monotonic_increase")
  if (all(nonzero < 0)) return("monotonic_decrease")
  first_neg <- which(nonzero < 0)[1]
  first_pos <- which(nonzero > 0)[1]
  if (first_pos < first_neg) return("rise_then_depress")
  if (first_neg < first_pos) return("depress_then_recover")
  "complex"
}

extract_curve_features_one <- function(df, value_col) {
  df <- df %>%
    filter(is.finite(time_hr), is.finite(.data[[value_col]])) %>%
    arrange(time_hr)
  if (nrow(df) < 2) return(tibble())

  t <- df$time_hr
  v <- df[[value_col]]
  dt <- diff(t); dv <- diff(v)
  valid_slope <- is.finite(dt) & dt > 0 & is.finite(dv)
  slopes <- dv[valid_slope] / dt[valid_slope]
  slope_midpoints <- ((head(t, -1) + tail(t, -1)) / 2)[valid_slope]
  seg_auc <- segment_auc(t, v)
  split_time <- median(seg_auc$t_mid, na.rm = TRUE)
  early_auc <- sum(seg_auc$auc[seg_auc$t_mid <= split_time])
  late_auc  <- sum(seg_auc$auc[seg_auc$t_mid >  split_time])

  baseline_value <- v[1]
  final_value <- v[length(v)]
  peak_idx <- which.max(v); trough_idx <- which.min(v)
  peak_value <- v[peak_idx]; trough_value <- v[trough_idx]
  peak_after_baseline <- peak_value - baseline_value
  depression_abs <- if (peak_idx < length(v)) max(peak_value - final_value, 0) else 0

  vmax_idx <- if (length(slopes) > 0) which.max(slopes) else NA_integer_
  min_slope_idx <- if (length(slopes) > 0) which.min(slopes) else NA_integer_
  curvature <- diff(slopes)
  inflection_idx <- if (length(curvature) > 0) which.max(abs(curvature)) + 1L else NA_integer_

  tibble(
    baseline_value = baseline_value,
    final_value = final_value,
    peak_value = peak_value,
    trough_value = trough_value,
    time_to_peak = t[peak_idx],
    time_to_trough = t[trough_idx],
    auc_total = trapezoid_auc(t, v),
    auc_early = early_auc,
    auc_late = late_auc,
    delta_auc_late_minus_early = late_auc - early_auc,
    late_early_auc_ratio = safe_divide(late_auc, early_auc),
    initial_slope = slopes[1],
    vmax = if (length(slopes) > 0) max(slopes) else NA_real_,
    time_to_vmax = if (!is.na(vmax_idx)) slope_midpoints[vmax_idx] else NA_real_,
    min_slope = if (length(slopes) > 0) min(slopes) else NA_real_,
    time_to_min_slope = if (!is.na(min_slope_idx)) slope_midpoints[min_slope_idx] else NA_real_,
    inflection_time = if (!is.na(inflection_idx)) slope_midpoints[inflection_idx] else NA_real_,
    metabolic_scope = peak_after_baseline,
    final_delta = final_value - baseline_value,
    depression_abs = depression_abs,
    metabolic_depression_index = safe_divide(depression_abs, abs(peak_after_baseline)),
    resilience_ratio = safe_divide(final_value, peak_value),
    stability_cv = safe_divide(sd(v), abs(mean(v))),
    trajectory_class = classify_trajectory(slopes),
    n_timepoints = nrow(df)
  )
}

cliffs_delta <- function(x, y) mean(sign(outer(x, y, "-")))

                 "#0072B2", "#D55E00", "#F0E442")
  setNames(okabe_ito[seq_along(levels)], levels)
}
```

# 5 Curve Feature Extraction

Features are extracted for two **windows**, which play the role of 04’s
stress contexts:

-   `acute_0_2h`: the five dense reads (0–2 h), the early response.
-   `full_0_18.75h`: all seven reads, including the overnight endpoint.

and for two **metrics**: `fold_change` (RFU / T0) and
`metabolism_per_area_mm2_measurement` (fold change / shell area).

``` r
windows <- list(acute_0_2h = 2, full_0_18.75h = Inf)
metrics <- c("fold_change", "metabolism_per_area_mm2_measurement")
```

# 6 Screen: Which Features Separate the Six Stresses?

For each window × metric × feature, a Kruskal-Wallis test across the six
stresses. Effect size is rank epsilon-squared (ε² = H / (n − 1); 0 = no
separation, 1 = perfect). P-values are BH-adjusted across all screened
features.

``` r
feature_stress_screen <- feature_long %>%
  group_by(window, value_metric, feature) %>%
  summarise(
    n = n(),
    kw_H = unname(kruskal.test(value ~ factor(treatment_group))$statistic),
    kw_p = kruskal.test(value ~ factor(treatment_group))$p.value,
    .groups = "drop"
  ) %>%
  mutate(epsilon_sq = kw_H / (n - 1),
         kw_p_bh = p.adjust(kw_p, "BH")) %>%
  arrange(desc(epsilon_sq))

write_csv(feature_stress_screen, file.path(out_dir, "feature_stress_screen.csv"))

knitr::kable(
  feature_stress_screen %>%
    slice_head(n = 20) %>%
    transmute(window, value_metric, feature, n,
              epsilon_sq = round(epsilon_sq, 3),
              kw_p_bh = signif(kw_p_bh, 3)),
  caption = "Top 20 curve features separating the six stresses"
)
```

## 7.2 What sets each stress apart (one-vs-rest)

For each stress separately, Cliff’s delta of every feature in that
stress vs the other five pooled (positive = higher in this stress), with
Wilcoxon p BH-adjusted within stress.

``` r
stress_signature <- feature_long %>%
  group_by(window, value_metric, feature) %>%
  group_modify(function(df, key) {
    map_dfr(stress_levels, function(g) {
      x <- df$value[df$treatment_group == g]
      y <- df$value[df$treatment_group != g]
      tibble(stress = g,
             median_stress = median(x), median_rest = median(y),
             cliffs_delta = cliffs_delta(x, y),
             wilcox_p = suppressWarnings(wilcox.test(x, y)$p.value))
    })
  }) %>%
  ungroup() %>%
  group_by(stress) %>%
  mutate(wilcox_p_bh = p.adjust(wilcox_p, "BH")) %>%
  ungroup()

write_csv(stress_signature, file.path(out_dir, "stress_signature_one_vs_rest.csv"))

top_by_stress <- stress_signature %>%
  group_by(stress) %>%
  slice_max(abs(cliffs_delta), n = 3, with_ties = FALSE) %>%
  ungroup()
```

# 8 Cross-validated Prediction (leave-one-oyster-out)

A screen over \~80 features × contexts overfits easily. As in 04, the
honest test is out-of-sample: **leave one oyster out**, select the
top-*k* features by ε² *using only the remaining 71 oysters*, fit a
linear discriminant analysis (LDA) on the z-scored features, and predict
the held-out oyster’s stress. Chance accuracy with six balanced classes
is 1/6 ≈ 0.17.

``` r
loo_lda <- function(wide, k) {
  # wide: trace_id, treatment_group, feature columns
  feats_all <- setdiff(names(wide), c("trace_id", "treatment_group"))
  y <- factor(wide$treatment_group, levels = stress_levels)
  preds <- character(nrow(wide))
  for (i in seq_len(nrow(wide))) {
    train <- wide[-i, ]
    # feature selection inside the fold (no leakage)
    eps <- map_dbl(feats_all, function(f) {
      v <- train[[f]]
      if (sd(v) == 0) return(-Inf)
      unname(kruskal.test(v ~ factor(train$treatment_group))$statistic)
    })
    feats <- feats_all[order(eps, decreasing = TRUE)][seq_len(k)]
    mu <- map_dbl(feats, ~ mean(train[[.x]]))
    sdv <- map_dbl(feats, ~ sd(train[[.x]]))
    xtr <- scale(as.matrix(train[, feats]), center = mu, scale = sdv)
    xte <- scale(as.matrix(wide[i, feats]), center = mu, scale = sdv)
    fit <- tryCatch(MASS::lda(xtr, grouping = y[-i], tol = 1e-8),
                    error = function(e) NULL)
    preds[i] <- if (is.null(fit)) NA_character_ else
      as.character(predict(fit, xte)$class)
  }
  tibble(trace_id = wide$trace_id, observed = as.character(y), predicted = preds)
}
```

## 10.4 Interpretation

The tables above are regenerated on every render. Read them with these
points in mind:

-   **Magnitude vs shape.** If the leading features are capacity traits
    (AUC, vmax, final value), the stresses differ mainly in *how much*
    metabolism they allow. If timing and ratio features (time to vmax,
    late/early ratio, resilience ratio) also rank highly, the stresses
    differ in *how* the response unfolds. That is the stronger basis for
    fingerprinting stresses from resazurin alone.
-   **Confusion structure.** Stresses that are confused with one another
    in the LOO-CV matrix produce indistinguishable resazurin phenotypes
    at this sampling density, even if their mean AUCs differ.
-   **Plate confound.** With one plate per stress, a replicated design
    (≥ 2 plates per stress, positions randomised) is needed before a
    stress signature can be separated from a plate effect.

## 10.5 Recommended next steps

1.  Add stress names to `layout.csv` (`treatment.group`) and re-render
    05.00 → 05.1.
2.  Replicate plates within each stress to break the plate × stress
    confound.
3.  Add reads between 2 h and 18.75 h: the overnight gap leaves most
    shape features unresolved.
4.  If these animals are followed for survival, join per-individual
    survival to `stress_index.csv` and test whether the index predicts
    outcome within each stress (the individual-level version of notebook
    04).
