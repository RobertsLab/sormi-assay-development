`Resazurin/outputs`

## DESCRIPTION

Data and figures generated by knitting the R Markdown scripts in `Resazurin/code/`. Each subdirectory here is named identically to the `.Rmd` that produces it (e.g., `01.00-resazurin-20260831-mgig-OAE-36C/` is written by `Resazurin/code/01.00-resazurin-20260831-mgig-OAE-36C.Rmd`) and, conversely, every `.Rmd` in `Resazurin/code/` writes to exactly one subdirectory here.

These are generated files, not source data — re-knitting the corresponding `.Rmd` regenerates the contents. See the "Expected outputs" section at the top of each `.Rmd` for a description of the specific files it writes.

---

## FILES

- `<name>/figures/` — Plots generated by the corresponding `.Rmd`.
- `<name>/*.csv` — Summary/intermediate data tables (e.g., AUC values, metabolism data, pairwise statistics) generated by the corresponding `.Rmd`.
