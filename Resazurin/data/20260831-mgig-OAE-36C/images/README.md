`Resazurin/data/20260831-mgig-OAE-36C/images`

## DESCRIPTION

Images of OAE- and control-treatment oysters with ruler for measurements, and their corresponding ImageJ-annotated versions used to derive `area_mm2.measurement` values in the sibling `*-ImageJ.csv` files.

---

## FILES

- `OAE-01.jpg`, `OAE-01-ImageJ.jpg` — Raw and ImageJ-annotated image of all 46 OAE-treatment individuals.

- `controls-01.jpg`, `controls-01-ImageJ.jpg` — Raw and ImageJ-annotated image of 45 control-treatment individuals.

- `controls-02.jpg`, `controls-02-ImageJ.jpg` — Raw and ImageJ-annotated image of the one remaining control-treatment individual (`C-27`) photographed separately.
